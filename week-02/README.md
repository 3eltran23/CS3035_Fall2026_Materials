# Week 2 Materials

## Opening the Lecture in Google Colab

To open the lecture notebook in Google Colab, first open
[L021 — Introduction to Python](L021-Intro2Python.ipynb) on GitHub. In the
browser's address bar, replace `github.com` with `githubtocolab.com`, and then
press **Enter**.

For example, change:

```text
https://github.com/3eltran23/CS3035_Fall2026_Materials/blob/main/week-02/L021-Intro2Python.ipynb
```

to:

```text
https://githubtocolab.com/3eltran23/CS3035_Fall2026_Materials/blob/main/week-02/L021-Intro2Python.ipynb
```
