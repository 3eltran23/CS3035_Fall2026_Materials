# Verification Materials

These files help students verify their Python, Kotlin, and C development environments. Each language folder contains a minimal Hello World program that students run directly.

Run all commands from this `verification` directory. You may use the integrated terminal in Visual Studio Code or a standard terminal provided by your operating system.

| Tool | Verification command | Expected result |
|---|---|---|
| Python | Run both `python/hello.py` and `python/python_setup.ipynb` using the `CS3035` environment | Hello World and Python 3.14 version from both files |
| Kotlin | Run both `kotlin/Main.kt` and `kotlin/kotlin_setup.ipynb` in IntelliJ IDEA | Hello World and Kotlin version from both files |
| C | Compile `c/hello.c`, then run the resulting executable | `Hello, CS 3035!` |

The Python and Kotlin notebooks are supplied in their respective verification folders. Compiler commands for C differ slightly between operating systems; consult the main lab instructions.
